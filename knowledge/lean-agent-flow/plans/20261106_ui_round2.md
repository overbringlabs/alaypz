# Plan: UI round 2 — theme-aware design, cards, drawer, replay, Extromino

Date: 2026-11-06 · branch main · base HEAD `5bf2d50` (owner-only control + daisy theme restore)

## Operator asks (a–i)

- a) Theme switching must actually apply — the custom design is hardcoded dark, so only daisy-internal components follow `data-theme`. Make the whole design system theme-aware (both themes usable).
- b) "Claim name"/"Start game" buttons vertically misaligned next to the claim input (`.input` renders a `div.fieldset.mb-2` wrapper; the row is `flex items-center`).
- c) Duplicate key legend (navbar + Session header) — keep one place. Decent down to iPhone 5S (320×568 CSS px).
- d) No lazy tables: leaderboard → cards with rank, name, score, lines, level, end reason, date, board canvas. **No monospace font anywhere** (ranks, scores, `#focused-piece`, piece text, kbd chips, access string).
- e) Recent results (lobby) → same card approach, listed **descending by score** (`Scores.list_top/1` already orders `desc score, desc inserted_at` with `preload: :player`).
- f) Clicking a result / leaderboard card opens a daisyUI **side drawer (right side)** with the complete session data; same on the Leaderboard page.
- g) Drawer shows a **Replay** action: replays the session at **1x/2x/5x/10x**. Engine is deterministic from seed → record the input sequence per game; old rows without a recording → replay disabled.
- h) **Deslopify** the UI: consistent alignment/spacing/states, no monospace outside real code, keep the established neon brand.
- i) Pages say **"Extromino"** (tetromino + Elixir), never "Alaypz" — namespace stays `Alaypz.*` in code.

Constraint: **no switching between games while playing** — switching/spectating stays lobby-only (current view-local focus model is final; no work there).

## Key decisions

- Theme-aware via daisy base classes (`bg-base-100/200`, `border-base-300`, `text-base-content`) — daisy vars follow `data-theme`; the board surface `.alaypz-board` stays dark in both themes (a neon screen).
- Session-header key legend kept, navbar one removed (legend lives where the keys act).
- Recent results = top by score (`Scores.list_top(5)`), per operator.
- Replay = server-driven stepper in `ReplayLive` (Elixir engine; the replay page owns its own engine instance — **not** routed through `Games.input`), tick-based recording `{tick, action}`; inputs apply only while `:playing`.
- Drawer = LV-state overlay with the daisy drawer look (right side), not the checkbox-driven `drawer` component.
- `Game.apply/2` public on the engine; the game process and `Alaypz.Replay` both use it.
- Card name is plain text (the whole card clicks → drawer; the drawer holds the `/<name>` link) — avoids nested click/link conflicts.
- No monospace anywhere, including kbd chips (sans bold) and the access string.
- Extromino is display-only: `Alaypz.*` namespace, `AlaypzWeb`, `Alaypz.Games` etc. unchanged.
- No mid-game switching — lobby-only focus is final.
